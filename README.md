# MyStudyBuddy

A study management web application developed as part of my Software Application Development assessment at Republic Polytechnic.

## About the Project

MyStudyBuddy helps students organise their academic activities by managing study sessions, to-do lists and personal learning goals.

## Features

- **Study Sessions:** Add, view, edit and delete study sessions.
- **To-Do List:** Create and manage tasks with descriptions and deadlines.
- **Study Goals:** Create, edit and delete goals, with the option to highlight important goals.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- EJS
- HTML
- Bootstrap

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure Node.js is installed.
4. Open a terminal and run:

   ```bash
   npm install
   node app.js
   ```

5. Open `http://localhost:3000` in your browser, assuming the application is configured to use port 3000.

## Limitations

The application uses in-memory storage rather than a database, so data is reset when the server restarts.
